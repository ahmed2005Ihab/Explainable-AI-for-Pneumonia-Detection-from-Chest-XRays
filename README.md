## Pipeline — Run in Order

### Notebook 1 · Preprocessing
Shared pipeline used by all three models.

- Loads and validates all 26,684 DICOM files
- EDA: class distribution, bounding box statistics, pixel intensity stats, sample images
- Builds a **balanced binary dataset**: 9,555 positives + 9,456 negatives (≈50/50)
- **Stratified 70 / 15 / 15 split on `patientId`** — no data leakage
- Z-score normalizes each image and saves as `<id>_full.npy` (224 × 224 × 3)
- Saves positive-only ROI crops as `<id>_roi.npy` for XAI evaluation
- Outputs: `labels.csv`, `train_ids.csv`, `val_ids.csv`, `test_ids.csv`, `xai_examples.csv`

### Notebook 2 · CheXNet (DenseNet-121)
```
Backbone      : DenseNet-121 (ImageNet pretrained, 6.95 M params)
Head          : Dropout(0.3) → Linear(1024, 1)
Loss          : BCEWithLogitsLoss  pos_weight=1.573
Optimizer     : Adam  lr=1e-4 → 5e-5 (after unfreeze)
Batch         : 8 physical × 4 accumulation = 32 effective
Freeze        : denseblock1+2 frozen for 3 epochs
Early stop    : patience=3  →  stopped at epoch 4
```
**Test results:** AUC=0.8804 · AP=0.8125 · F1=0.79 · threshold=0.3975

**XAI:**
- Grad-CAM on `features.denseblock4` · Pointing Game = **40%** (4/10) · CAM Intensity Ratio = **1.66**
- LIME (500 samples, top-5 superpixels)
- SHAP GradientExplainer (2–4 background images)
- Integrated Gradients (n_steps=3, riemann_right, zero baseline)

### Notebook 3 · EfficientNet-B4
```
Backbone      : EfficientNet-B4 (ImageNet pretrained, 17.55 M params)
Head          : Dropout(0.4) → Linear(1792, 1)
Input size    : 380 × 380  (compound-scaled native resolution)
Loss          : BCEWithLogitsLoss  (no pos_weight — balanced subset)
Optimizer     : Adam  lr=1e-4 → 5e-5 (after unfreeze)
Batch         : 8 physical × 4 accumulation = 32 effective
Freeze        : stages 0–6 frozen for 3 epochs
Epochs run    : 15  (early stop triggered at epoch 15)
```
**Test results:** AUC=**0.8948** (highest of all 9 models) · AP=0.8281 · F1=0.80 · threshold=0.4243

**XAI:**
- Grad-CAM on `features[-1]` (last MBConv stage) · Pointing Game = **30%** (3/10)
- LIME (500 samples) — correctly localises opacity regions despite partial Grad-CAM displacement
- SHAP GradientExplainer (2–4 background images)
- Integrated Gradients (n_steps=3)

### Notebook 4 · Xception
```
Backbone      : Xception (ImageNet pretrained, 20.81 M params)
Head          : Dropout(0.4) → Linear(2048, 1)
Input size    : 299 × 299
Loss          : Focal Loss  α=0.611  γ=2.0
Optimizer     : Adam  lr=1e-5
Batch         : 4 physical (AMP enabled)
Freeze        : backbone frozen for 2 epochs
Epochs run    : 10  (best val_loss=0.0534 at epoch 10)
```
**Test results:** AUC=0.8903 · F1=**0.81** · Acc=**0.82** · threshold=0.5093

> The near-0.50 optimal threshold means Focal Loss produced well-calibrated probability outputs — no threshold recalibration needed for clinical use.

**XAI:**
- Grad-CAM on final separable conv block · Pointing Game = **30%** (3/10)
- LIME (500 samples)
- SHAP GradientExplainer
- Integrated Gradients

## XAI Summary

| Method | Type | Library | Config |
|---|---|---|---|
| **Grad-CAM** | Gradient × activation | custom PyTorch hooks | Last conv block per model |
| **LIME** | Perturbation (SLIC superpixels) | `lime` | 500 samples, top-5 features |
| **SHAP** | Shapley values | `shap` | GradientExplainer, 2–4 background images |
| **Integrated Gradients** | Path attribution | `captum` | Zero baseline, n_steps=3 |

| Model | Pointing Game | CAM Intensity Ratio |
|---|---|---|
| CheXNet | **40%** (4/10) | **1.66** |
| EfficientNet-B4 | 30% (3/10) | — |
| Xception | 30% (3/10) | — |

**CAM Intensity Ratio > 1** → model activates more strongly *inside* radiologist-annotated lesion regions than outside. CheXNet's ratio of 1.66 confirms 66% higher attention on pathological regions vs. background.

## GPU Memory Strategy (4 GB VRAM)

All three models were trained on a 4 GB GPU using:

| Technique | Effect |
|---|---|
| Physical batch = 8 (or 4 for Xception) | Fits activations in VRAM |
| Gradient accumulation ×4 | Effective batch = 32 without memory cost |
| `zero_grad(set_to_none=True)` | Fully frees gradient tensors each step |
| `torch.amp.autocast` (AMP) | ~40% memory reduction via float16 |
| `torch.cuda.empty_cache()` each epoch | Returns freed memory to OS |
| `gc.collect()` each epoch | Clears Python-side tensor references |
| Backbone frozen during warm-up | ~60% fewer gradients stored in early epochs |

Set this before any CUDA tensor is created:
```python
import os
os.environ["PYTORCH_CUDA_ALLOC_CONF"] = "expandable_segments:True"
```
