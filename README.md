## Pipeline

Run the notebooks **in order**:

### Notebook 1 — Preprocessing
- Loads and validates all DICOM files
- EDA: class distribution, bounding box analysis, sample images, pixel statistics
- Builds a balanced binary dataset (9,555 positive / 9,456 negative)
- Stratified 70 / 15 / 15 split on `patientId` (no data leakage)
- Z-score normalizes and saves all images as `.npy` files
- Saves `labels.csv`, split CSVs, and `xai_examples.csv` (20 held-out XAI patients)

### Notebook 2 — CheXNet (DenseNet-121)
- Pretrained DenseNet-121 backbone, classifier replaced with `Dropout(0.3) → Linear(1)`
- Backbone frozen for 3 epochs → full fine-tune at lr=5e-5
- `BCEWithLogitsLoss` with `pos_weight=1.573`
- Physical batch=8, gradient accumulation ×4 (effective batch=32), AMP
- Early stopping triggered at epoch 4 · best val\_loss=0.5555
- **Test AUC=0.8804**, AP=0.8125, optimal threshold=0.3975
- XAI: Grad-CAM (`denseblock4`), LIME, SHAP (GradientExplainer), Integrated Gradients
- Quantitative XAI: Pointing Game=40% (4/10), CAM Intensity Ratio=1.66

### Notebook 3 — EfficientNet-B4
- Pretrained EfficientNet-B4, classifier replaced with `Dropout(0.4) → Linear(1)`
- Images resized to 380×380 (native compound-scaled resolution) inside DataLoader
- Backbone frozen for 3 epochs → full fine-tune at lr=5e-5
- `BCEWithLogitsLoss` (no pos\_weight, near-balanced subset)
- Trained for all 15 epochs · best val\_loss=0.4287
- **Test AUC=0.8948** (highest of all nine models), AP=0.8281, optimal threshold=0.4243
- XAI: Grad-CAM (`features[-1]`), LIME, SHAP (GradientExplainer), Integrated Gradients
- Quantitative XAI: Pointing Game=30% (3/10)

### Notebook 4 — Xception
- Pretrained Xception, classifier replaced with `Dropout(0.4) → Linear(1)`
- `Focal Loss` (α=0.611, γ=2.0) for well-calibrated probability outputs
- Physical batch=4, AMP, backbone frozen for 2 epochs
- Trained for 10 epochs · best val\_loss=0.0534, val\_AUC=0.8821
- **Test AUC=0.8903**, optimal threshold=0.5093 (near-perfectly calibrated)
- Best accuracy (0.82) and macro F1 (0.81) among the three models
- XAI: Grad-CAM, LIME, SHAP (GradientExplainer), Integrated Gradients

## XAI Methods

| Method | Type | Library | Applied To |
|---|---|---|---|
| **Grad-CAM** | Gradient × activation | `captum` / custom hooks | All 3 models |
| **LIME** | Perturbation (superpixels) | `lime` | All 3 models |
| **SHAP** | Shapley values (GradientExplainer) | `shap` | All 3 models |
| **Integrated Gradients** | Path attribution | `captum` | All 3 models |

### Quantitative XAI Evaluation

Computed on 10 positive held-out patients using radiologist bounding boxes:

| Model | Pointing Game | CAM Intensity Ratio |
|---|---|---|
| CheXNet | 40% (4/10) | 1.66 |
| EfficientNet-B4 | 30% (3/10) | — |
| Xception | 30% (3/10) | — |

**CAM Intensity Ratio > 1** means the model's Grad-CAM activation is higher inside lesion regions than outside. CheXNet's ratio of 1.66 confirms it attends 66% more strongly to annotated lesion regions than to background.

## Memory Configuration

All three models were trained on a **4 GB VRAM GPU** using:

- Physical batch size: 8 (CheXNet, EfficientNet-B4) / 4 (Xception)
- Gradient accumulation: ×4 → effective batch = 32
- `torch.amp.autocast` mixed-precision training
- `optimizer.zero_grad(set_to_none=True)` for full gradient memory release
- `torch.cuda.empty_cache()` + `gc.collect()` after each epoch
- `PYTORCH_CUDA_ALLOC_CONF=expandable_segments:True`
